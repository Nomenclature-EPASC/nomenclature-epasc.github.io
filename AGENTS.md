# Règles de travail pour ce dépôt

- Tu peux modifier les fichiers du dépôt local pour répondre aux demandes de l’utilisateur.
- Ne crée jamais de commit et ne pousse jamais de modifications vers GitHub sans avoir demandé et obtenu l’accord explicite de l’utilisateur.
- Ne modifie pas la base Supabase ni les données hébergées en ligne, sauf demande explicite de l’utilisateur.
